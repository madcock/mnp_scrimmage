Seattle Monday Night Pinball Scrimmages


This is not the official MNP website!

This site will only be used for team scrimmages that are not part of the regular MNP season. None of the results of these matches will count towards standings in a main season, and none of these results will be submitted to Match Play Events, affect player IPR, or be included in the main MNP website stats.

Thanks to Slayers and Drain in Hell for being the first to play a match here and test out this experimental site!

The next time for scrimmages will be:

  • March 16th, during Spring Break week
  • April 20th, during 420 week
  • Playoffs weeks (starting April 27th), only for teams that don't make playoffs
Contact Michael Adcock if you've set something up with another team and are interested in a scrimmage during these weeks. If captains need to be adjusted for these scrimmages, let me know.

Can't find your match in the long list? Why not use the new MY MATCH feature from the main menu. If you're logged in, it should take you to your match!

Since results here won't affect the real site, matches can be abandoned without completing them if you want. And of course all of this is optional and no one is required to use it. Just figured it might be a fun way to get some practice in!

For more information on Seattle Monday Night Pinball, visit the official website.
